# Architecture Decision Framework

A practical framework for architectural decision-making, requirements analysis, trade-off evaluation, and ADR documentation.

## Features

- Focused instructions and workflows for the skill's domain.
- Practical examples and implementation guidance.
- Best practices and validation checks where applicable.

## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/architecture
cp SKILL.md .claude/skills/architecture/SKILL.md
```

## Usage

Ask your AI coding assistant to use **Architecture Decision Framework** when handling a related task. It should follow the instructions in `SKILL.md`.
